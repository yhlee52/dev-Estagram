# Archive

이 폴더는 현재 작업의 primary 문서가 아닌 historical 문서를 보관합니다.

보관 대상:

- **완료된 테마의 scope 문서** (`V0_1_*`, `V0_2_*`): 해당 테마가 완료되면 이곳으로
  옮깁니다. 구현 당시의 goals/non-goals 기록이며, 현재 동작은 코드와 현행 문서가
  기준입니다.
- **MVP-era 참고 문서** (`MVP10_EXTERNAL_POST_FORMAT.md`, `MVP12_ASSET_VIEWER_SCOPE.md`):
  format history / 과거 scope 상세.
- **historical MVP validation / v0.0.0 문서** (`MVP*_TEST_PROCEDURE.md`,
  `RELEASE_CHECKLIST_v0.0.0.md`, `SMOKE_TEST_v0.0.0.md`).

Archived 문서는 개발 기록이나 회귀 확인에는 유용하지만, 현재 release behavior를
그대로 반영하지 않을 수 있습니다.

현재 실행/검증/계획 기준 문서:

- `../ROADMAP.md`
- `../V0_3_X_INGESTION_PLAN.md` (현재 테마)
- `../EXTERNAL_POST_PACKAGE_GUIDE.md`
- `../RELEASE_0_0_RUNBOOK.md`
- `../RELEASE_0_0_CHECKLIST.md`
