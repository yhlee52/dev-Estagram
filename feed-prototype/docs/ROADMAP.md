# 로드맵

## v2.3.x 메시지 대화방

현재 화면 표기는 v2.3.1입니다. v2.3.1은 새 대화·초대에 팔로우가 필요하고 기존 방 전송에는 필요하지 않은 규칙을 반영합니다.

- 기존 1:1 메시지를 대화방으로 이전하고 여러 명이 참여하는 방, 초대, 나가기를 지원합니다.
- 새 대화 시작과 새 참여자 초대는 대상 계정을 팔로우해야 합니다. 이미 참여 중인 방에서는 팔로우를 취소해도 메시지를 보낼 수 있습니다.
- JPEG, PNG, GIF, WebP 이미지를 메시지로 보낼 수 있습니다. 이미지당 최대 5MB이며, 방 참여자만 열 수 있습니다.

버전은 `MAJOR.MIDDLE.MINOR`입니다. MAJOR는 제품 성격이 바뀔 때, MIDDLE은 기능
테마가 바뀔 때, MINOR는 그 테마 안의 집중된 변경에 사용합니다. 표시되는 릴리즈
라벨은 `src/config/appVersion.ts`가 기준입니다.

## 현재 구현

- v2.2.x는 스마트 홈 검색 테마입니다. v2.2.0은 인물 관계·장소·검색 API와
  편집기·import 경로, v2.2.1은 홈과 탐색의 공유 검색창·URL·복귀,
  v2.2.2는 후보 실패·키보드·조건 chip·문서를 정리합니다. [스마트 홈 검색](SMART_HOME_SEARCH_PLAN.md)에 검색 의미와
  기존 DB의 멘션 재계산 절차가 있습니다.

- v2.1.x는 로컬 SNS의 한국어·탐색·프로필 UX 테마입니다. v2.1.0 한국어 문구·KST
  표시·IME, v2.1.1 계정 검색과 URL 기반 탐색, v2.1.2 페이지 단위 프로필,
  v2.1.3 커버와 링크, v2.1.4 게시글 고정, v2.1.5 탐색 복귀와 접근성 정리를
  구현했습니다. 자세한 동작과 검증은
  [UX 개선 계획](UX_IMPROVEMENT_PLAN.md)을 보세요.
- v2.0.0은 로컬 PC 실행 기준선입니다. 소셜 피드의 기본 기능(게시글·댓글·좋아요·
  북마크·알림·1:1 메시지)을 사용할 수 있습니다.
- 데이터는 로컬 PostgreSQL과 `EXTERNAL_POSTS_DIR`의 파일로 관리합니다. `incoming/`
  감시 import와 상대 경로 자산의 로컬 복사가 현재 운영 경로입니다.
- API 모드가 기능 검증용이며 mock 모드는 UI 데모 상태로 유지합니다.
