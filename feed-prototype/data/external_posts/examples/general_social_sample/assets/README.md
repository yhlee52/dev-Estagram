# general_social_sample assets

이 폴더는 `general_social_sample/feed_posts.json`이 참조하는 asset 파일 위치를 설명합니다.

- Import script는 실제 asset file을 복사하지 않습니다.
- `asset.url`은 브라우저에서 접근 가능한 URL/path여야 합니다.
- 이 sample은 큰 image binary를 repo에 넣지 않습니다.
- 성공 preview를 확인하려면 작은 sample image를 `feed-prototype/public/assets/generated/` 아래에 두고 JSON의 `/assets/generated/...` path와 맞춥니다.
- 일부 asset 파일이 없으면 viewer fallback 확인용으로 동작할 수 있습니다.

참조 URL:

```text
/assets/generated/social_sample_avatar.png
/assets/generated/social_sample_001_01.png
/assets/generated/social_sample_001_02.png
/assets/generated/social_sample_001_03.png
/assets/generated/social_sample_002_01.png
/assets/generated/social_sample_003_01.png
/assets/generated/social_sample_003_02.png
```
